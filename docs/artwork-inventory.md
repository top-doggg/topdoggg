## Studio completion rule

Do not guess physical metadata. Confirm the following for every record: creation year, exact medium, unframed dimensions, framed dimensions if relevant, original/digital status, edition size and artist proofs, condition, location, availability, retail price, minimum acceptable price, exhibition history, publication history, rights restrictions, and a high-resolution master-file location.
